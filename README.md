# 歯科クリニック 新規患者分析システム

新規患者データの登録・集計・分析を行うウェブアプリです。

## 機能

- 新規患者登録（患者番号・紹介経路・担当スタッフ・学校など）
- ダッシュボード（月別推移・KPI）
- 紹介経路分析 / スタッフ別分析 / 学校・地域分析
- クロス集計・トレンド分析
- 選択項目（診療科目・来院経路・スタッフ）の管理画面
- CSVエクスポート

## データ保存について

データはブラウザの **localStorage** に保存されます。  
同じブラウザ・デバイスであれば次回アクセス時もデータが保持されます。

## 技術構成

- 純粋な HTML / CSS / JavaScript（フレームワーク不使用）
- Chart.js（グラフ描画）
- サーバー不要・静的ファイル1枚構成
